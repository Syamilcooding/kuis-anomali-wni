# 🇮🇩 Kuis Kepribadian: Anomali WNI

Kuis kepribadian berbasis web yang lucu untuk menebak "tipe warga negara" seperti apa kamu di dunia nyata.

🚀 **[Mainkan Kuisnya di Sini!](https://kuis-anomali-wni.vercel.app/)**

## 📌 Fitur Utama
- Single Page Application (SPA)
- Desain Modern & Responsif: Antarmuka (UI) yang rapi di HP maupun laptop.
- Mode Gelap/Terang (Dark Mode)
- Logika Dinamis: Menghitung skor terbanyak dari pertanyaan untuk menampilkan kemungkinan hasil unik.

## 🛠️ Teknologi yang Digunakan
- **HTML5** murni
- **Vanilla JavaScript** (ES6)
- **Tailwind CSS** (via CDN)
- **Vercel** (untuk Hosting & CI/CD otomatis)

## 📂 Struktur Proyek
```text
kuis-anomali-wni/
├── index.html    # Halaman utama berisi struktur UI lengkap
├── style.css     # Kustomisasi styling dan class utilitas pendukung (d-block, d-none)
└── script.js     # Data JSON soal, logika kuis, dan manipulasi DOM
